# Hong Kong Editorial Showcase

这组 3:4 海报使用 `laopai-visual` 与 `hong-kong-editorial` 生成，覆盖六种介绍场景：

1. `CITY NOTES`：城市写作与个人创作
2. `HONG KONG`：日常街景与红色小巴
3. `CONTENT SYSTEM`：内容生产工作流
4. `ON AIR`：播客与声音封面
5. `STREET PORTRAIT`：街头人物摄影
6. `VISUAL ARCHIVE`：持续扩展的个人风格库

`prompts/` 保存了每张图使用的完整提示词。参考图只用于提炼编辑排版、克制色彩和复古印刷材料；所有场景与构图均重新设计。
