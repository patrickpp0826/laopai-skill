# 纸隙墨潮 · Showcase 2026-09

这组六张 4:5 样图用于检验 `paper-ink-fragment-style` 能否跨题材保持同一套视觉语言。

| 编号 | 题材 | 主要检验点 | motif mode | 点缀色 |
| --- | --- | --- | --- | --- |
| 01 | 人物肖像 | 面部识别点、银发开放线、纸白留口 | `none` | 朱红 |
| 02 | 动物 | 黑色主体内的纸白裂隙、动态轮廓 | `none` | 青蓝 |
| 03 | 环境场景 | 大尺度深色结构、雨水与负空间 | `auto` | 朱红 |
| 04 | 产品静物 | 圆形与皮革结构、局部高密度细节 | `sparse` | 橙红 |
| 05 | 生活叙事 | 双人关系、手部动作、蒸汽和水果 | `auto` | 橙红 |
| 06 | 抽象概念 | 无文字表达“逆流选择”、纸白通道 | `none` | 洋红 |

完整提示词位于 [`prompts/`](prompts/)。示例中的主体、构图和点缀色都是变量，不属于固定风格层。

## 观察重点

- 画面是否保留有效裸纸，而不是在白底上叠一层均匀纸纹。
- 开放回找线是否参与找形，而不是变成贴着轮廓的装饰刮痕。
- 蓝黑色块是否被纸白缺口和白色干笔切开。
- 积色边、回流花、羽化湿边和颗粒沉降是否出现在不同区域。
- 没有固定条纹、卷线、网格或排线组合跨作品反复出现。
