# 港式编辑视觉

```yaml
id: hong-kong-editorial
name: 港式编辑视觉
outputs: [cover, card, illustration, selfie]
subjects: [article, concept, person, street, object]
default_ratios:
  cover: "16:9"
  card: "3:4"
  illustration: "16:9"
  selfie: "4:5"
style_anchors:
  - 香港城市生活的真实光线、构图和印刷材料
  - 黑、米白、电车红为主色，辅助色克制
  - 旧报纸、巴士票、纤维纸、网点与胶片颗粒
  - 少字、强层级、单一视觉中心
must_preserve:
  - 港风来自可见视觉语言，而不是霓虹关键词拼贴
  - 文字少且处于安全区
  - 一个画面只选一个明确的叙事主体
avoid_when_applying:
  - 紫蓝赛博朋克和未来 HUD
  - 随机繁体招牌、伪英文、乱码
  - 过度橙青调色、塑料皮肤、廉价 glitch
```

## 适用

文章封面、小红书卡片、长文场景图和以真实人物照片为参考的街头人像。
