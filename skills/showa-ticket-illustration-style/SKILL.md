# 昭和票券插画生图配方

用户提供的 19 张参考图均为昭和时期的日本宝くじ票券。此 Skill 沿用用户的“日本复古邮票风”叫法，但视觉依据是票券：没有邮票齿孔、邮戳或固定邮资布局。将共通的平面插画、印刷材料和信息层级用于新主题，不继承参考票券中的具体图案与文字。

## 必读参考

- 每次组装提示词前读 [references/style-fingerprint.md](references/style-fingerprint.md)，使用其中的固定层、色彩、构图与禁用项。
- 需要完整提示词模板或纠偏时读 [references/prompt-template.md](references/prompt-template.md)。

## 输入

- `{subject}`：用户的新主题。可为人物、动物、花木、物件、风景或抽象概念。
- `{format}`：`ticket`（完整票券）或 `illustration`（只保留插画语言）；默认 `ticket`。文章封面和内容卡片也可采用票券式分区。
- `{orientation}`：横向或纵向；默认按用途选择，不把横版参考图旋转后直接沿用。
- `{palette}`：从参考的米白、暗蓝、松绿、朱红、樱粉、芥末黄中取 3–5 色；允许按主题调整主色关系。
- `{copy}`：用户指定的标题、短标签、日期或编号。未指定时不虚构真实机构、年代、兑奖信息或邮资。
- `{aspect_ratio}`、`{must_include}`、`{must_avoid}`：按用户要求填写。

## 使用流程

1. 区分内容与风格。参考图里的儿童、花、鸟、桥、果蔬和节令，只是题材实例，不能默认带进新图。
2. 在英文正向提示词开头放入固定风格层，再写用户的新主体、票券版式、色彩、材料和画幅。票券模式应给插画区、标题信息区、号码章区清楚的面积关系；插画模式可以舍弃号码章。
3. 只在用户给出确切文字时将其写入画面要求。需要可读中文、日文或精确数字时，优先生成无字底图和预留字区，后期排版；不要让图像模型伪造可信的历史票券。
4. 合并专属负向约束与用户禁用项，输出英文 Positive prompt、英文 Negative prompt、中文核对稿和画幅。用户明确要求生成图片时再调用图像生成工具。

## 参考与原创边界

参考图仅用于抽取材料、色块、印刷误差、构图和字体气质。不得复刻现有票券的编号、机构名称、奖券花纹、角色造型、完整布局或历史字标。花纹号码章使用新绘制的简化曲线纹样，不描摹参考图的防伪图案。

如果用户明确要求“邮票”，可以在独立创作中加入齿孔，但要说明齿孔来自用户的目标媒介，而非这批参考图；默认不加齿孔或邮戳。

## 交付检查

- [ ] 新主题在缩略图可读，且没有借用参考图的具体角色或场景。
- [ ] 插画是简化、纸片般的色块组织，细线只用于必要结构。
- [ ] 票券模式有明确的信息区、插画区和可选的号码章区；文字不压住主体。
- [ ] 色数、网点、纸纹和轻微套印偏差受控；没有全图均匀做旧滤镜。
- [ ] 没有把齿孔、邮戳、真实银行或历史彩票文字误当成本组参考的固定风格。
- [ ] 英文提示词与中文核对稿表达相同内容。
