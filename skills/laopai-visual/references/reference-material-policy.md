# 设计参考素材政策

用户提供的参考图默认只用于本次分析和 Skill 规则开发。除非用户明确证明拥有权利并要求收录，否则不要复制、打包、公开或提交原图。

## 可以提炼

- 构图关系：主影像与信息区比例、网格、留白、竖排与横排关系。
- 类型特征：粗宋、黑体、圆体、窄体、书写感、字重与字距。
- 图形语法：牌匾、圆章、菱形、票券、边框、路牌、色块与印章的位置关系。
- 材料与成像：新闻纸、纤维纸、丝网套色、半调网点、胶片颗粒、直闪与混合光源。
- 色彩关系：主色、辅助色、明度层级和套色方式。
- 叙事方式：单一视觉中心、城市切片、主图加少量辅助图、双语信息层级。

## 不可提取为资产

- 原始图片、截图、摄影、插画、贴纸素材和水印。
- 店名、品牌名、Logo、字标、商标图案、独特包装和具体广告文案。
- 可被追溯为特定作品的完整构图、角色、图标组合或装饰套件。
- 从像素图描摹出来的字形、书法或定制字体。

## 转译方法

1. 把参考描述为可观察特征，不写“复制某图”或“完全一样”。
2. 至少改变主体、信息结构、比例或构图中的两项，形成独立设计。
3. 品牌位置使用用户提供且有权使用的品牌资产；否则使用通用占位或留白。
4. 最终提示词加入：不生成现有 Logo、品牌字标、水印、署名或可识别的第三方角色。
5. 公共仓库只提交提炼后的文字规则和自行生成、权利清晰的示例。
