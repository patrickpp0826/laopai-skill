## 选择规则

- 现在只有一个风格：默认使用 `hong-kong-editorial`。
- 新风格加入后，按 `META.md` 的 outputs 与 subjects 筛选。
- 用户明确指定 style ID 时，不混用第二个风格。
- 用户只给内容、没有给风格时，推荐三个适配的 style，除非用户要求自动决定。
