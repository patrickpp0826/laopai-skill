# 纸隙墨潮生图配方

把固定风格层应用到全新内容，先输出英文生图提示词和中文核对稿；用户明确要求生成图片时，再调用可用的图像生成工具。

最终提交给图像模型的提示词中，禁止出现画师姓名、社交账号、作品名、网站名或“模仿某人”等替代表述。

## 适用场景

- 用户要求“用这个风格画某物”或明确点名“纸隙墨潮”。
- 为人物、动物、环境、生活场景、产品、静物或抽象概念生成稳定一致的提示词。
- 用户提供参考图，并明确只想迁移画法。
- 用户要求检查、修正或扩展已有的纸隙墨潮提示词。

不把参考图中的角色、服装、道具、地点、姿势或构图默认带入新图。

## 必读参考

- 每次组装提示词前读取 [references/style-fingerprint.md](references/style-fingerprint.md)，取得固定风格层、配色和负向约束。
- 需要套用模板或查看跨题材示例时读取 [references/prompt-template.md](references/prompt-template.md)。
- 修改配方或回归测试时读取 [references/test-plan.md](references/test-plan.md)。

## 输入变量

- `{subject}`：主体及必要外观；只写用户指定或完成画面所需的信息。
- `{scene}`：环境、时间与空间关系；未指定时使用简洁、不抢主体的场景。
- `{mood}`：情绪和氛围；未指定时从主体语义中选择克制的单一倾向。
- `{composition}`：景别、视角、主体位置、留白与动势。
- `{aspect_ratio}`：画幅比例；未指定时按内容选择，肖像优先 `4:5`，横向环境优先 `16:9`，静物优先 `1:1` 或 `4:5`。
- `{must_include}`：必须出现的内容元素。
- `{must_avoid}`：用户额外排除的内容或表现。
- `{motif_mode}`：装饰痕迹策略，可选 `none`、`auto`、`sparse`；默认 `auto`。`none` 禁止装饰痕迹，`auto` 仅在负空间或结构节奏确有需要时使用，`sparse` 最多使用 1–2 个。

缺失变量可合理补全，但不得借用参考图内容填空。若用户只给出 `{subject}`，保持其余内容简洁，让风格而非故事设定成为主要增量。

## 固定层与变量层

### 固定风格层

默认完整使用 style fingerprint 中的 6 条英文 `style_dna_anchors`，保持原句或只做必要的语法衔接。只有上下文长度明确受限时才可缩成 4 条，且必须同时保留：

1. 裸纸比例与水色层数；
2. 越界回找线的开放比例、重复数量和偏移距离；
3. 蓝黑墨块面积、纸白切口和单层硬阴影；
4. 至少三类局部湿水色反应；
5. 五色上限与单一跳色面积；
6. 局部细节上限与可选的、由当前构图推导的残缺痕迹。

## 受控不规则性

不要只写 `random lines`、`watercolor texture` 或 `ornamental fragments`。这些词容易生成贴着轮廓的装饰线、均匀纸纹滤镜和几乎不可见的纹样。

每张图必须安排前两种可定位痕迹；第三种只按 `{motif_mode}` 选择：

- **找形事故**：焦点边缘有错位回找线，主要连接处有越界线、回钩或未擦净起稿线。
- **水色事故**：不同区域分别出现积色暗边、回流花、羽化湿边与颗粒沉降中的至少三种。
- **构图痕迹（可选）**：不得调用固定纹样词库。需要时只从本图已经存在的轮廓、连接、折线、边缘或负空间方向中抽取 1–2 个局部痕迹，并让每个痕迹被裁切、擦除或水色遮住 `40%–80%`。

`motif_mode` 的执行规则：

- `none`：不添加任何独立装饰痕迹。
- `auto`：默认模式；没有明确构图功能就省略，必要时最多添加 1 个由当前主体或场景几何派生的痕迹。
- `sparse`：最多添加 1–2 个由当前主体或场景几何派生的痕迹；不得跨作品复用相同符号组合。

随机痕迹必须服务于形体连接、色块边缘或负空间节奏。禁止把均匀噪点、等距飞溅和全画同强度纸纹当作手绘感。

### 可替换内容层

只由 `{subject}`、`{scene}`、`{mood}`、`{composition}`、`{aspect_ratio}`、`{must_include}`、`{must_avoid}` 和 `{motif_mode}` 决定。不得把固定风格层写成“黑衣人物”“武器”“鸟”“特定花纹服装”等题材要求。

## 工作流

### 1. 选风格

确认本 Skill 被触发，读取 style fingerprint。默认使用核心配方；只有用户明确要求更克制、更浓烈、偏冷或偏暖时，才在允许范围内调整点缀色密度和背景覆盖率。

### 2. 填内容

从用户请求提取八个变量。区分“必须出现”和“可自由补全”。将参考图中的内容全部视为不可继承，除非用户本轮明确重新指定。

### 3. 组装 prompt

按以下顺序构造英文正向提示词：

1. `style anchors`
2. `subject`
3. `scene + mood`
4. `composition + lighting`
5. `texture + finish + aspect ratio`

风格锚点必须位于正向提示词最前面，并占总文本约 35%–45%，不得少于前 1/3。随后生成语义同步的中文核对稿。英文用于生图，中文不得引入英文中没有的新内容。

负向提示词按 `exclusive_negatives + universal_negatives + {must_avoid}` 组装，去重后输出英文；不要把正向风格锚点误塞进负向提示词。

### 4. 生图

- 用户只要提示词：输出英文 positive prompt、英文 negative prompt、中文核对稿和画幅比例，不生成图片。
- 用户明确要求直接生图：先完成提示词质检，再调用可用的图像生成工具；将英文 positive prompt 作为主提示词，将 negative prompt 作为约束写入同一次请求。
- 用户提供参考图：向模型明确“style only”，并附上 `do_not_copy_from_refs` 的限制。

### 5. 复盘

生成后从五项检查：纸白是否存在、线条是否松而不闭合、黑块是否稳住主体、彩色渗化是否受控、原图内容是否被复制。一次只修正影响最大的偏差：

- 太干净：增加连接处越界线与回钩线；不要只增加背景飞溅。
- 像数字水彩滤镜：把水色拆成至少三个局部事故区，分别指定积边、回流花、羽化湿边或颗粒沉降，并禁止全画均匀纸纹。
- 固定纹样再次出现：把 `{motif_mode}` 改为 `none`；若构图确实需要痕迹，则只保留 1 个从当前主体或场景几何派生、被破坏 `40%–80%` 的局部痕迹。
- 太脏乱：将 `{motif_mode}` 改为 `none`，减少点缀色色簇，恢复纸白缓冲。
- 太像动画平涂：删除规则闭合线和分层阴影，强调透明渗化与不透明擦痕。
- 太像参考图：强化“只借材质语法，不借主体、姿势、服装、道具、地点或构图”，并重写内容层。

## 参考图用法

参考图只用于核对这些风格变量：媒介叠层、线条闭合程度与越界方式、黑白面积关系、湿水色事故类型、细节密度、纸面肌理和纹样破坏方式。

禁止继承：角色身份、脸型组合、发型、服装、配饰、武器、动物、道具、动作、叙事关系、背景地点、镜头位置、人物数量、画面分区、画中画安排及标志性构图。若用户要求保留某项，必须把它作为本轮 `{must_include}` 明确写入内容层。

## 输出格式

```markdown
英文 Positive prompt：...

英文 Negative prompt：...

中文核对稿：...

画幅：...
```

如果用户明确要求生图，在以上内容通过检查后执行生成，并展示结果。

## 质检清单

- [ ] 正向提示词最前 1/3 是风格锚点。
- [ ] 风格层没有出现具体角色、服装、道具、地点或动作。
- [ ] 内容层完整表达用户的新主体，而非参考图主体。
- [ ] 英文和中文含义一致。
- [ ] 最终提示词不含画师姓名、账号、作品名、网站名或流派名替代观察。
- [ ] 同时包含纸白、非闭合细线、蓝黑大色块、透明渗化和局部不透明擦痕。
- [ ] 至少一个主要连接处存在越界线、回钩线或未擦净起稿线，而不是只有贴边断线。
- [ ] 积边、回流花、羽化湿边与颗粒沉降至少出现三类，且位于分离区域。
- [ ] 点缀色只使用一种，低于画面 `8%`，分布为 `3–6` 个不等大色簇。
- [ ] 脸、手或主体识别点较密，次要区域主动简化。
- [ ] `{motif_mode}` 已明确执行：`none` 为 0 个；`auto` 为 0–1 个；`sparse` 为 1–2 个。
- [ ] 若存在构图痕迹，它只从当前主体或场景的几何关系派生，被裁切、擦除或水色遮住 `40%–80%`，且没有复用固定条纹、卷线、网格或排线符号组合。
- [ ] 裸纸与浅洗区可见纸纹，深色块没有覆盖同强度的统一纸纹滤镜。
- [ ] negative prompt 已合并专属约束、通用约束和 `{must_avoid}`。
- [ ] 使用参考图时已加入 style-only 与禁止复制内容／构图的说明。
- [ ] `{aspect_ratio}` 与主体类型和构图一致。
